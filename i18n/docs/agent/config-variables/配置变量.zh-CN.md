# 配置变量

配置由 `src/config.py` 使用 Pydantic 设置加载。该应用默认读取 `.env`。

## 所需变量

| 变量 | 是否必填 | 默认 | 目的 |
|----------|----------|---------|---------|
| `DEEPSEEK_API_KEY` | 是的 | 没有任何 | 用于 DeepSeek/OpenAI 兼容聊天调用的 API 密钥 |
| `DEEPSEEK_BASE_URL` | 否 | `https://api.deepseek.com` | OpenAI 兼容提供商的基本 URL |
| `DEEPSEEK_MODEL` | 否 | `deepseek-chat` | `LLMClient`使用的聊天模型 |
| `DATABASE_URL` | 否 | `sqlite+aiosqlite:///butler.db` | SQLAlchemy 异步数据库 URL |

## 本地发展

从 `.env.example` 创建 `.env` 并仅在本地机器上填写真实密钥。

形状示例：

```env
DEEPSEEK_API_KEY=sk-your-actual-key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=sqlite+aiosqlite:///butler.db
```

不要提交 `.env` 或真实的 API 密钥。

## 测试

使用占位符键进行测试：

```bash
DEEPSEEK_API_KEY=test uv run pytest -q
```

测试应该模拟 LLM 调用，并且不应依赖于占位符密钥是否有效。

## 企业微信自建应用

| 变量 | 是否必填 | 默认 | 目的 |
|----------|----------|---------|---------|
| `WECHAT_CORP_ID` | 否 | `""` | 用于消息加密/解密的企业 CorpID |
| `WECHAT_TOKEN` | 否 | `""` | 回调 URL 验证Token |
| `WECHAT_ENCODING_AES_KEY` | 否 | `""` | 用于加密/解密消息的 43 字符 Base64 AES 密钥 |
| `WECHAT_AGENT_ID` | 否 | `""` | 自建应用AgentID |

当 `WECHAT_CORP_ID` 和 `WECHAT_TOKEN` 都设置时，注册 `/api/wechat/callback` 路由。回调使用**被动加密 XML 回复**（适用 5 秒超时）。

```env
WECHAT_CORP_ID=ww1234567890abcdef
WECHAT_TOKEN=YourRandomToken123
WECHAT_ENCODING_AES_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WECHAT_AGENT_ID=1000005
```

## 企业微信智能机器人

| 变量 | 是否必填 | 默认 | 目的 |
|----------|----------|---------|---------|
| `WECHAT_ROBOT_TOKEN` | 否 | `""` | 智能机器人回调Token |
| `WECHAT_ROBOT_ENCODING_AES_KEY` | 否 | `""` | 用于机器人消息加密的 43 字符 Base64 AES 密钥 |

设置 `WECHAT_ROBOT_TOKEN` 时，注册 `/api/wechat/robot/callback` 路由。机器人回调使用**通过 `response_url` POST 进行主动回复**（无 5 秒超时）。加密的 `receiveid` 是空字符串 `""`（不是 CorpID）。

```env
WECHAT_ROBOT_TOKEN=YourRobotToken
WECHAT_ROBOT_ENCODING_AES_KEY=YourRobotEncodingAESKey
```

与自建应用的主要区别：
- 消息格式：智能机器人专用JSON（`from.userid`、`text.content`、`chatid`、`response_url`）
- 回复机制：POST JSON 到 `response_url`（仅支持 `markdown` 和 `template_card` 消息类型 — `text` 返回 errcode 40008）
- 加密接收ID：`""`（空字符串）而不是CorpID

## 企业微信组Bot Webhook

| 变量 | 是否必填 | 默认 | 目的 |
|----------|----------|---------|---------|
| `WECHAT_WEBHOOK_URL` | 否 | `""` | 用于主动推送的群机器人 Webhook URL |

设置后，将在应用启动时创建 `WechatWebhookClient` 实例，用于发送主动组通知。

```env
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx
```

## 变更指导

- 在`src/config.py`中为`Settings`添加新的环境变量。
- 一起更新 `.env.example`、此文件和配置测试。
- 对日志、测试、文档和提交的文件保密。
- 与直接在业务逻辑中读取 `os.environ` 相比，更喜欢显式配置字段。
