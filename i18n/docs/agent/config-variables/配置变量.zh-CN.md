# 配置变量

配置由 `src/config.py` 通过 Pydantic Settings 加载，默认读取 `.env` 文件。

## 必需变量

| 变量 | 必需 | 默认值 | 用途 |
|----------|----------|---------|---------|
| `DEEPSEEK_API_KEY` | 是 | 无 | DeepSeek/OpenAI 兼容聊天的 API 密钥 |
| `DEEPSEEK_BASE_URL` | 否 | `https://api.deepseek.com` | OpenAI 兼容提供商的基础 URL |
| `DEEPSEEK_MODEL` | 否 | `deepseek-chat` | `LLMClient` 使用的聊天模型 |
| `DATABASE_URL` | 否 | `sqlite+aiosqlite:///butler.db` |  SQLAlchemy 异步数据库 URL |

## 本地开发

从 `.env.example` 创建 `.env`，仅在本地机器填写真实密钥。

示例格式：

```env
DEEPSEEK_API_KEY=sk-your-actual-key
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=sqlite+aiosqlite:///butler.db
```

不要提交 `.env` 或真实 API 密钥。

## 测试

测试使用占位密钥：

```bash
DEEPSEEK_API_KEY=test uv run pytest -q
```

测试应 mock LLM 调用，不应依赖占位密钥的有效性。

## 企业微信自建应用

| 变量 | 必需 | 默认值 | 用途 |
|----------|----------|---------|---------|
| `WECHAT_CORP_ID` | 否 | `""` | 企业 CorpID，用于消息加解密 |
| `WECHAT_TOKEN` | 否 | `""` | 回调 URL 验证 Token |
| `WECHAT_ENCODING_AES_KEY` | 否 | `""` | 43 位 Base64 AES 密钥，用于消息加解密 |
| `WECHAT_AGENT_ID` | 否 | `""` | 自建应用 AgentID |

当 `WECHAT_CORP_ID` 和 `WECHAT_TOKEN` 同时设置时，注册 `/api/wechat/callback` 路由。回调使用**被动加密 XML 回复**（有 5 秒超时限制）。

```env
WECHAT_CORP_ID=ww1234567890abcdef
WECHAT_TOKEN=YourRandomToken123
WECHAT_ENCODING_AES_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WECHAT_AGENT_ID=1000005
```

## 企业微信智能机器人

| 变量 | 必需 | 默认值 | 用途 |
|----------|----------|---------|---------|
| `WECHAT_ROBOT_TOKEN` | 否 | `""` | 智能机器人回调 Token |
| `WECHAT_ROBOT_ENCODING_AES_KEY` | 否 | `""` | 43 位 Base64 AES 密钥，用于机器人消息加解密 |

当 `WECHAT_ROBOT_TOKEN` 设置时，注册 `/api/wechat/robot/callback` 路由。机器人回调使用**主动回复模式（通过 `response_url` POST）**（无 5 秒超时限制）。加解密时 `receiveid` 为空字符串 `""`（非 CorpID）。

```env
WECHAT_ROBOT_TOKEN=YourRobotToken
WECHAT_ROBOT_ENCODING_AES_KEY=YourRobotEncodingAESKey
```

与自建应用的关键区别：
- 消息格式：智能机器人专用 JSON（`from.userid`、`text.content`、`chatid`、`response_url`）
- 回复机制：POST JSON 到 `response_url`（仅支持 `markdown` 和 `template_card` 两种 msgtype，使用 `text` 返回 errcode 40008）
- 加密 receiveid：`""`（空字符串）而非 CorpID

## 企业微信群机器人 Webhook

| 变量 | 必需 | 默认值 | 用途 |
|----------|----------|---------|---------|
| `WECHAT_WEBHOOK_URL` | 否 | `""` | 群机器人 Webhook URL，用于主动推送 |

设置后，应用启动时创建 `WechatWebhookClient` 实例，用于发送主动群通知。

```env
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx
```

## 变更指南

- 在 `src/config.py` 的 `Settings` 中添加新的环境变量。
- 同时更新 `.env.example`、此文件和配置测试。
- 不要在日志、测试、文档和已提交文件中包含密钥。
- 优先使用显式配置字段，而非在业务逻辑中直接读取 `os.environ`。
