## 1. 开发环境（本地开发）

### 一、要求

- Python 3.13+
- [uv](https://docs.astral.sh/uv/) 包管理器
- git

### 2. 克隆项目

```bash
git clone https://github.com/assle/personal-butler-agent.git
cd personal-butler-agent
```

### 3.配置.env

```bash
cp .env.example .env
```

编辑 `.env` 并填写所需值：

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxx        # Required
# Keep defaults for the rest
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=sqlite+aiosqlite:///butler.db

# WeChat Work config (leave empty for dev, does not affect debug endpoint)
WECHAT_CORP_ID=
WECHAT_TOKEN=
WECHAT_ENCODING_AES_KEY=
WECHAT_AGENT_ID=
WECHAT_WEBHOOK_URL=
```

### 4.安装依赖项

```bash
uv sync
uv pip install pytest pytest-asyncio httpx
```

### 5. 启动开发服务器

```bash
uv run uvicorn src.main:app --host 0.0.0.0 --port 8000
```

### 6. 测试

```bash
# Run all tests
DEEPSEEK_API_KEY=test uv run pytest -q

# Run specific test file
DEEPSEEK_API_KEY=test uv run pytest tests/test_fitness.py -v
```

### 7. 手动API调试

```bash
curl -X POST http://localhost:8000/api/debug/message \
  -H "Content-Type: application/json" \
  -d '{"user_id":"assle","message":"打卡 今天练胸 卧推80kg5组8次"}'
```

### 8.本地企业微信回调测试（可选）

要在本地测试企业微信回调，请使用 ngrok 公开本地服务：

```bash
# Terminal 1: Start service
uv run uvicorn src.main:app --host 0.0.0.0 --port 8000

# Terminal 2: Start ngrok
ngrok http 8000
```

在企业微信自建应用后台设置ngrok公共地址作为回调地址：

```
https://xxxx.ngrok-free.dev/api/wechat/callback
```

## 2、生产环境（云服务器部署）

使用 Ubuntu 22.04+/24.04 的示例。

### 一、要求

- Ubuntu云服务器（已配置DNS，例如`butler.assle.online`）
- 开放端口：80 (HTTP)、443 (HTTPS)
- 域名解析为服务器IP

### 2. 安装基础工具

```bash
# Update system
sudo apt update && sudo apt upgrade -y

# Install uv
curl -LsSf https://astral.sh/uv/install.sh | sh
source ~/.cargo/env

# Install Caddy (auto HTTPS reverse proxy)
sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/gpg.key' | sudo gpg --dearmor -o /usr/share/keyrings/caddy-stable-archive-keyring.gpg
curl -1sLf 'https://dl.cloudsmith.io/public/caddy/stable/debian.deb.txt' | sudo tee /etc/apt/sources.list.d/caddy-stable.list
sudo apt update && sudo apt install -y caddy
```

### 3. 克隆存储库

```bash
git clone https://github.com/assle/personal-butler-agent.git /opt/personal_butler_agent
cd /opt/personal_butler_agent
```

### 4.安装依赖项

```bash
uv sync
uv pip install pytest pytest-asyncio httpx
```

### 5.配置.env

```bash
cp .env.example .env
```

使用实际生产值编辑 `.env`：

```ini
DEEPSEEK_API_KEY=sk-xxxxxxxx
DEEPSEEK_BASE_URL=https://api.deepseek.com
DEEPSEEK_MODEL=deepseek-chat
DATABASE_URL=sqlite+aiosqlite:///butler.db

# WeChat Work self-built app config (required, otherwise callback route is not registered)
WECHAT_CORP_ID=ww1234567890abcdef
WECHAT_TOKEN=YourRandomToken123
WECHAT_ENCODING_AES_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WECHAT_AGENT_ID=1000005

# WeChat Work group bot webhook (optional, push disabled if empty)
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx
```

### 6.配置Caddy反向代理+HTTPS

```bash
sudo tee /etc/caddy/Caddyfile << 'CADDY'
butler.assle.online {
    reverse_proxy 127.0.0.1:8000
}
CADDY

sudo systemctl reload caddy
```

Caddy 自动获取 Let's Encrypt 证书 — 无需手动步骤。

### 7.配置systemd服务

```bash
sudo tee /etc/systemd/system/butler.service << 'EOF'
[Unit]
Description=Personal Butler Agent
After=network.target

[Service]
Type=simple
User=root
WorkingDirectory=/opt/personal_butler_agent
ExecStart=/root/.cargo/bin/uv run uvicorn src.main:app --host 127.0.0.1 --port 8000
Restart=always

[Environment]
DEEPSEEK_API_KEY=sk-xxxxxxxx
DATABASE_URL=sqlite+aiosqlite:///butler.db
WECHAT_CORP_ID=ww1234567890abcdef
WECHAT_TOKEN=YourRandomToken123
WECHAT_ENCODING_AES_KEY=xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx
WECHAT_AGENT_ID=1000005
WECHAT_WEBHOOK_URL=https://qyapi.weixin.qq.com/cgi-bin/webhook/send?key=xxxxx

[Install]
WantedBy=multi-user.target
EOF
```

### 8. 启动服务

```bash
sudo systemctl daemon-reload
sudo systemctl enable --now butler
sudo systemctl status butler   # Confirm status is active (running)
```

### 9.配置企业微信回调地址

在企业微信自建应用后台设置回调地址：

```
https://butler.assle.online/api/wechat/callback
```

输入与`.env`匹配的Token和EncodingAESKey，点击保存完成URL 验证。

### 10. 常用操作

```bash
# Check service status
sudo systemctl status butler

# View logs
sudo journalctl -u butler -f

# Restart service
sudo systemctl restart butler

# Stop service
sudo systemctl stop butler

# Update code and restart
cd /opt/personal_butler_agent
git pull origin main
sudo systemctl restart butler
```

### 11. 验证生产部署

```bash
# Local curl test (inside server)
curl -X POST http://127.0.0.1:8000/api/debug/message \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","message":"你好"}'

# Public curl test
curl -X POST https://butler.assle.online/api/debug/message \
  -H "Content-Type: application/json" \
  -d '{"user_id":"test","message":"你好"}'
```

## 架构概述

```
                      ┌──────────────────────────────┐
  Dev (localhost)     │   POST /api/debug/message     │     ┌─────────────┐
    curl / Frontend ──▶   Plain JSON request/response  │─────▶│ SQLite      │
                      │                              │     └─────────────┘
                      │   POST /api/wechat/callback   │
  Production          │   Encrypted XML request/response│    ┌─────────────┐
    WeChat Work ─────▶   (only registered when        │─────▶│ DeepSeek    │
                      │    WECHAT_CORP_ID +           │     └─────────────┘
                      │    WECHAT_TOKEN are set)      │
                      └──────────────────────────────┘
                              ▲
                              │
              Caddy (HTTPS) ──┘   Production only
              systemd             Production only
```
